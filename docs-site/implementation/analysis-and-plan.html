3. 实施决策（主控拍板，agent 执行）

  1. T1 path widget：实现而非删改。 场景意图明确（SVG 子集 d + stroke + 绑定切换），

引擎已有贝塞尔基建（timeline path-follow cubic）。范围：SVG 路径子集解析 （M/L/H/V/Q/T/C/S/Z 绝对+相对）、HTML 侧内联 <svg><path>（render.go 加 case）、 canvas 侧栅格化（fill+stroke）并注册。d 变形不做插值动画（binding 切换即换形， 文档如实说明）。若实施中遇结构性阻塞，降级方案：场景改用现有 widget 并记录原因。

  1. T2：改测试（16:9 是当前 videoNode 的有意行为）。
  2. T3：修生成器——把手写章节并入生成输出（永久保留），再重新生成；

zh 镜像 api/zh/widgets.md 同样处理。禁止"只覆写不保留"。

  1. S1：非回环绑定即发 token（复用 X-Qorm-Token 机制），启动时打印 + 大字警告；

/mcp、/update、/rollback、/window、POST /measure 强制校验。

  1. S2：loader 加载期 error（动态 bracket key 的 computed 直接拒绝，附原因）。
  2. S3：UpdateConfig/__QORM_UPDATE__ 增加可选 revocation 数组，两个校验点接入，文档说明。
  3. S4：hash 失配且 bundle 声明版本时附版本提示，不改 fail-closed 语义。
  4. D1 MVP 边界：步骤 mount_scene / simulate_event（dispatch action）/ set_state；

断言 state_equals / node_exists / node_not_exists / text_equals / prop_equals； JSON 报告 + exit code。advance_time / flush_async / host-mock 留下轮。
